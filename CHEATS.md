# Beta dev cheat codes

> **Beta-only tools.** These codes exist for testing during the beta and will be removed at alpha (v1.0). The game goes closed source beyond the Steam release.

| Code | Effect |
|---|---|
| `7474` | God mode |
| `1974` | Skip the current stage |
| `2012` | Level select (opens a keypad to pick the level; from build 025, 91-98 jump to bosses 1-8) |
| `6969` | Noclip on / off (walk through walls and props) |
| `0000` | All off (god mode and noclip off) |

## How to enter a code

- **PC:** type the four digits (number row or numpad) on the **title screen** or while the game is **paused**.
- **Mobile / touch:** on the title screen, **long-press the logo for 2 seconds** to open the keypad, then tap the digits.

## What changes when a cheat is used

- A **CHEAT ON** tag shows on screen while god mode or noclip is active. After `0000`, the tag reads **CHEATED** for the rest of that run.
- **High scores are not saved** for any run in which a code was used. Starting a fresh game from the title clears the flag.
